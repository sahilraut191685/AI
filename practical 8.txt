
N = 8

board = [[0 for i in range(N)] for j in range(N)]

def isSafe(row, col):

    # Check same row
    for i in range(col):
        if board[row][i] == 1:
            return False

    # Check upper diagonal
    i = row
    j = col
    while i >= 0 and j >= 0:
        if board[i][j] == 1:
            return False
        i -= 1
        j -= 1

    # Check lower diagonal
    i = row
    j = col
    while i < N and j >= 0:
        if board[i][j] == 1:
            return False
        i += 1
        j -= 1

    return True


def solve(col):

    # All queens are placed
    if col >= N:
        return True

    for row in range(N):

        if isSafe(row, col):

            board[row][col] = 1

            if solve(col + 1):
                return True

            # Backtracking
            board[row][col] = 0

    return False


if solve(0):
    for row in board:
        print(row)
else:
    print("No solution")






Practical 8: 8 Queens Problem using Backtracking
Aim: To implement the 8 Queens Problem using the Backtracking technique in Python.

Theory:

The 8 Queens Problem is a classical Artificial Intelligence problem in which eight queens must be placed on an 8 × 8 chessboard such that no two queens attack each other.

A queen can attack another queen horizontally, vertically and diagonally. Therefore, no two queens should be placed in the same row, column or diagonal.

Backtracking is an algorithmic technique used to solve problems by building a solution incrementally. It tries a possible choice, checks whether the choice satisfies the given constraints, and proceeds further if the choice is valid.

In this problem, queens are placed one column at a time. Before placing a queen, the algorithm checks whether the selected position is safe by examining the row and both diagonals on the previously processed side of the board.

If a safe position is found, the queen is placed and the algorithm recursively moves to the next column. If no valid position is available, the algorithm backtracks by removing the previously placed queen and tries another position.

The process continues until all eight queens are successfully placed.

Conclusion: The 8 Queens Problem is successfully solved using Backtracking by placing queens in safe positions while satisfying all chessboard constraints.
