
# Distance between cities
distance = {
    'A': {'A': 0, 'B': 10, 'C': 15, 'D': 20},
    'B': {'A': 10, 'B': 0, 'C': 35, 'D': 25},
    'C': {'A': 15, 'B': 35, 'C': 0, 'D': 30},
    'D': {'A': 20, 'B': 25, 'C': 30, 'D': 0}
}

# Calculate total distance of a route
def total_distance(route):
    total = 0

    for i in range(len(route) - 1):
        total += distance[route[i]][route[i+1]]

    # Return to starting city
    total += distance[route[-1]][route[0]]

    return total


# Generate new routes by swapping cities
def get_neighbors(route):
    neighbors = []

    for i in range(1, len(route)):
        for j in range(i + 1, len(route)):

            new_route = list(route)

            new_route[i], new_route[j] = new_route[j], new_route[i]

            neighbors.append(tuple(new_route))

    return neighbors


# Local Beam Search
K = 3
iterations = 5

# Initial routes
beam = [
    ('A', 'B', 'C', 'D'),
    ('A', 'C', 'B', 'D'),
    ('A', 'D', 'B', 'C')
]

print("Initial Routes:")
for route in beam:
    print(route, "Distance =", total_distance(route))

# Repeat the search
for step in range(iterations):

    candidates = []

    # Generate neighboring routes
    for route in beam:
        candidates.append(route)
        candidates.extend(get_neighbors(route))

    # Remove duplicate routes
    unique_routes = []

    for route in candidates:
        if route not in unique_routes:
            unique_routes.append(route)

    # Sort routes by distance
    unique_routes.sort(key=total_distance)

    # Keep only K best routes
    beam = unique_routes[:K]

    print("\nIteration", step + 1)

    for route in beam:
        print(route, "Distance =", total_distance(route))


# Best route
best_route = beam[0]

print("\nBest Route:")
print(" -> ".join(best_route), "->", best_route[0])

print("Minimum Distance =", total_distance(best_route))








Practical 4: Travelling Salesman Problem using Local Beam Search
Aim: To implement the Travelling Salesman Problem using Local Beam Search in Python.

Theory:

The Travelling Salesman Problem (TSP) is a well-known optimization problem in Artificial Intelligence. It involves finding the shortest possible route for a salesman who must visit every city exactly once and return to the starting city.

Local Beam Search is a heuristic search algorithm that maintains a fixed number of candidate states, represented by K. Instead of exploring only one solution at a time, it explores multiple candidate solutions simultaneously.

Initially, a set of candidate routes is generated. The algorithm evaluates each route using an objective function, which calculates the total travelling distance.

It then generates neighbouring solutions by modifying existing routes. The best K candidate solutions are selected based on their total distance. This process continues for a specified number of iterations.

The objective function is:
\[
Cost(Route)=\sum_{i=0}^{n-2}d(c_i,c_{i+1})+d(c_{n-1},c_0)
\]

Where:
- \(d(c_i,c_{i+1})\) represents the distance between consecutive cities.
- The last term represents the return journey to the starting city.
The algorithm attempts to minimize the total travelling distance.

Conclusion: The Travelling Salesman Problem is approached using Local Beam Search by maintaining and improving multiple candidate routes.
